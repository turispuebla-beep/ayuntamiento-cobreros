## 1. Manual de Usuario

### 1.1. Acceso al Portal

El portal web del Ayuntamiento de Cobreros está disponible en: **https://www.ayuntamientocobreros.com**

### 1.2. Registro de Usuario

**Pasos para registrarse:**
1. Haga clic en "Registrarse" o "Iniciar Sesión"
2. Complete el formulario con sus datos personales:
   - Nombre y apellidos
   - Correo electrónico
   - Teléfono
   - Dirección
   - Documento de identidad (DNI/NIE/Pasaporte)
   - Localidades de interés
3. Acepte los términos y condiciones
4. Complete el registro

**Requisitos:**
- Ser mayor de edad
- Proporcionar información veraz
- Tener un correo electrónico válido

### 1.3. Iniciar Sesión

1. Haga clic en "Iniciar Sesión"
2. Introduzca su correo electrónico y contraseña
3. Opcional: Active "Mantener sesión iniciada" para recibir notificaciones
4. Haga clic en "Iniciar Sesión"

### 1.4. Solicitar Cita Previa

**Pasos:**
1. Inicie sesión en el portal
2. Acceda a la sección "Citas Previas"
3. Seleccione el tipo de cita
4. Elija fecha y hora disponible
5. Complete los datos adicionales si se solicitan
6. Confirme la solicitud

**Notas importantes:**
- Las citas están sujetas a disponibilidad
- Recibirá confirmación por email
- Puede cancelar con al menos 24 horas de antelación

### 1.5. Solicitar Carné Micológico

**Pasos:**
1. Inicie sesión
2. Acceda a "Carnés" > "Carné Micológico"
3. Complete el formulario de solicitud
4. Revise la información
5. Envíe la solicitud

**Requisitos:**
- Estar registrado en el sistema
- Proporcionar documentación necesaria
- Pagar las tasas correspondientes

### 1.6. Recibir Notificaciones

**Tipos de notificaciones:**
- Notificaciones oficiales del ayuntamiento
- Confirmaciones de citas
- Alertas municipales
- Eventos y actividades

**Configuración:**
- Las notificaciones se envían por email
- Puede activar notificaciones push en el navegador
- Configure sus preferencias en su perfil

### 1.7. Recuperar Contraseña

Si olvidó su contraseña:
1. Haga clic en "¿Olvidaste tu contraseña?" en la pantalla de login
2. Introduzca su correo electrónico
3. Recibirá un enlace para restablecer la contraseña
4. El enlace expira en 1 hora
5. Siga las instrucciones para crear una nueva contraseña

## 2. Manual de Administrador

### 2.1. Acceso al Panel de Administración

**Acceso:**
1. Haga clic en el botón "ADMIN" en la esquina superior derecha
2. O acceda directamente desde el botón "Panel Admin" (si está visible)
3. Introduzca sus credenciales de administrador
4. Accederá al panel de administración

**Seguridad:**
- Use contraseñas seguras
- No comparta sus credenciales
- Cierre sesión al terminar

### 2.2. Gestión de Contenido

**Gestionar Anuncios:**
- Panel Admin > Gestión de Contenido > Anuncios
- Crear, editar o eliminar anuncios
- Programar publicación

**Gestionar Bandos:**
- Panel Admin > Gestión de Contenido > Bandos
- Publicar bandos oficiales
- Gestionar fechas de publicación

**Gestionar Cultura y Ocio:**
- Panel Admin > Gestión de Contenido > Cultura y Ocio
- Añadir eventos, lugares de interés, gastronomía
- Gestionar categorías

### 2.3. Gestión de Citas Previas

**Ver citas:**
- Panel Admin > Citas Previas
- Ver calendario de citas
- Filtrar por fecha, estado, tipo

**Gestionar citas:**
- Aprobar o rechazar citas
- Modificar fechas/horas
- Cancelar citas
- Enviar confirmaciones

**Configurar horarios:**
- Panel Admin > Citas Previas > Configurar Horarios
- Activar/desactivar días
- Configurar horarios de mañana y tarde
- Establecer disponibilidad

### 2.4. Gestión de Usuarios

**Ver usuarios:**
- Panel Admin > Usuarios
- Lista de usuarios registrados
- Filtrar y buscar usuarios

**Acciones:**
- Ver perfil de usuario
- Desactivar/activar usuarios
- Exportar lista de usuarios

### 2.5. Gestión de Administradores

**Crear administrador:**
- Panel Admin > Administradores > Crear Nuevo Administrador
- Complete el formulario
- Asigne permisos
- Guarde

**Gestionar administradores:**
- Ver lista de administradores
- Editar permisos
- Eliminar administradores (con precaución)

### 2.6. Gestión de Documentos

**Subir documentos:**
- Panel Admin > Documentos
- Complete el formulario
- Suba el archivo (opcional)
- Añada enlace externo (opcional)
- Publique

**Gestionar documentos:**
- Editar documentos existentes
- Eliminar documentos
- Organizar por categorías

### 2.7. Gestión de Avisos

**Crear aviso:**
- Panel Admin > Avisos
- Complete el formulario
- Seleccione destinatarios
- Programe envío (opcional)
- Envíe

**Ver estadísticas:**
- Panel Admin > Avisos > Estadísticas
- Ver tasas de apertura
- Ver historial de envíos

### 2.8. Backup y Restauración

**Crear backup:**
- Panel Admin > Base de Datos > Backup y Restauración
- Haga clic en "Crear Backup"
- El sistema crea backup automático cada 24 horas

**Restaurar desde backup:**
- Seleccione un backup de la lista
- Revise la fecha y descripción
- Haga clic en "Restaurar"
- Confirme la acción

**Exportar datos:**
- Exportar usuarios, administradores, documentos
- Formatos: JSON, CSV

### 2.9. Logs de Auditoría

**Ver logs:**
- Panel Admin > Base de Datos > Logs de Auditoría
- Ver acciones realizadas
- Filtrar por usuario, fecha, acción
- Exportar logs

**Información registrada:**
- Accesos de administradores
- Creación/eliminación de usuarios
- Cambios de configuración
- IP, timestamp, acciones

### 2.10. Estadísticas

**Ver estadísticas:**
- Panel Admin > Estadísticas
- Usuarios activos
- Citas previas
- Notificaciones enviadas
- Contenido publicado

## 3. Guía Técnica

### 3.1. Arquitectura del Sistema

**Tecnologías utilizadas:**
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Backend: Firebase (Firestore, Authentication, Storage, Cloud Functions)
- Hosting: Netlify
- PWA: Service Worker, Manifest

### 3.2. Estructura de Archivos

```
netlify-deploy/
├── index.html          # Página principal
├── manifest.json       # Configuración PWA
├── sw.js              # Service Worker
├── config.js          # Configuración
├── css/               # Estilos
├── js/                # Scripts JavaScript
│   ├── script.js      # Script principal
│   ├── admin-panel.js # Panel de administración
│   └── [módulos]      # Módulos adicionales
├── images/            # Imágenes
└── .well-known/       # Certificados y configuraciones
```

### 3.3. Módulos de Seguridad

**Sanitización de inputs:**
- `js/input-sanitizer.js` - Previene XSS e inyección SQL

**Protección CSRF:**
- `js/csrf-protection.js` - Tokens CSRF en formularios críticos

**Verificación backend:**
- `js/backend-verification.js` - Validación de permisos

**Rate limiting:**
- `js/rate-limiter.js` - Limita intentos de login y acciones

**Logs de auditoría:**
- `js/audit-log-system.js` - Registro de acciones

### 3.4. Base de Datos (Firestore)

**Colecciones principales:**
- `users` - Usuarios registrados
- `admins` - Administradores
- `appointments` - Citas previas
- `documents` - Documentos públicos
- `notifications` - Notificaciones
- `audit_logs` - Logs de auditoría
- `backups` - Backups del sistema

### 3.5. Configuración de Firebase

**Archivos de configuración:**
- `firestore.rules` - Reglas de seguridad Firestore
- `storage.rules` - Reglas de seguridad Storage
- `config.js` - Configuración del frontend

### 3.6. Service Worker (PWA)

**Funcionalidades:**
- Caché de recursos estáticos
- Funcionamiento offline básico
- Actualizaciones automáticas
- Notificaciones push

### 3.7. Integraciones

**Servicios externos:**
- Firebase (autenticación, base de datos, storage)
- reCAPTCHA v3 (protección contra bots)
- Netlify (hosting y CDN)

## 4. Procedimientos Operativos

### 4.1. Procedimiento de Backup Diario

**Frecuencia:** Automático cada 24 horas + manual bajo demanda

**Pasos:**
1. El sistema crea backup automático a las 02:00 AM
2. Los backups se almacenan en Firestore (colección `backups`)
3. Se mantienen los últimos 30 backups
4. Los backups antiguos se eliminan automáticamente

**Backup manual:**
1. Acceder al Panel Admin > Base de Datos
2. Hacer clic en "Crear Backup Manual"
3. Añadir descripción opcional
4. Confirmar

### 4.2. Procedimiento de Restauración

**Cuándo restaurar:**
- Pérdida de datos
- Error en actualización
- Necesidad de volver a un estado anterior

**Pasos:**
1. Acceder al Panel Admin > Base de Datos > Backup y Restauración
2. Seleccionar backup a restaurar
3. Revisar fecha y descripción
4. Hacer clic en "Restaurar"
5. Confirmar la acción
6. Verificar que la restauración fue exitosa

**Precauciones:**
- Realizar backup actual antes de restaurar
- Verificar que el backup es correcto
- Notificar a usuarios si es necesario

### 4.3. Procedimiento de Creación de Administrador

**Pasos:**
1. Acceder como administrador
2. Panel Admin > Administradores > Crear Nuevo Administrador
3. Completar formulario:
   - Nombre completo
   - Correo electrónico
   - Contraseña (mínimo 8 caracteres)
4. Verificar permisos
5. Guardar

**Verificaciones:**
- Email único
- Contraseña segura
- Permisos adecuados

### 4.4. Procedimiento de Gestión de Incidentes

**Tipos de incidentes:**
- Caída del servicio
- Error en funcionalidad
- Problema de seguridad
- Pérdida de datos

**Pasos:**
1. Identificar el incidente
2. Evaluar gravedad
3. Notificar a responsables
4. Aplicar solución temporal si es posible
5. Investigar causa raíz
6. Implementar solución permanente
7. Documentar incidente
8. Revisar y mejorar procedimientos

### 4.5. Procedimiento de Actualización

**Antes de actualizar:**
1. Crear backup completo
2. Revisar cambios en el código
3. Probar en entorno de desarrollo
4. Notificar a usuarios si es necesario

**Durante la actualización:**
1. Activar modo mantenimiento (opcional)
2. Desplegar nueva versión
3. Verificar que todo funciona
4. Desactivar modo mantenimiento

**Después de actualizar:**
1. Verificar funcionalidades críticas
2. Revisar logs de errores
3. Monitorear durante 24 horas
4. Documentar cambios

## 5. Plan de Contingencia

### 5.1. Escenarios de Contingencia

**Escenario 1: Caída del Servicio**
- **Causa:** Problema en hosting o Firebase
- **Acción:** Contactar con proveedores, activar backup si es necesario
- **Tiempo estimado de recuperación:** 1-4 horas

**Escenario 2: Pérdida de Datos**
- **Causa:** Error en actualización o ataque
- **Acción:** Restaurar desde backup más reciente
- **Tiempo estimado de recuperación:** 2-6 horas

**Escenario 3: Problema de Seguridad**
- **Causa:** Intrusión o vulnerabilidad
- **Acción:** Cerrar acceso, investigar, aplicar parches, cambiar credenciales
- **Tiempo estimado de recuperación:** 4-24 horas

**Escenario 4: Error en Funcionalidad Crítica**
- **Causa:** Bug en código o configuración
- **Acción:** Revertir cambios, aplicar hotfix
- **Tiempo estimado de recuperación:** 1-2 horas
